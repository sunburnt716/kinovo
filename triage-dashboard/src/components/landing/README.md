# Public website landing components

This folder now holds the reusable building blocks for the public-facing site.

## Current responsibilities

- `PublicNavbar` / `PublicFooter` / `PublicSiteShell` for the public site chrome.
- `Hero` for the landing page hero.
- `ProblemSection`, `SolutionsSection`, and `ResearchSection` for landing-page storytelling.
- `ClinicalQueuePreview` for the queue / dashboard preview graphic.
- `SectionHeader` and `StatCard` for reusable editorial layout primitives.

## Design direction

The public site uses a clinical editorial tone: serif headlines, monospaced metrics, restrained borders, and minimal rounding.
